# Agentic lure

This additional category serves a benign HTML comment asking explicitly
authorized security automation to request a unique canary path once. The
instruction requests no secret, command execution, external callback, or
access to another system.

```bash
docker compose up --detach --build
curl http://127.0.0.1:8085/
curl -H 'X-Audit-Agent: EXAMPLE-TEST' \
  http://127.0.0.1:8085/_canary/EXAMPLE-AI-AGENT-CHECK
```

Following the instruction is stronger evidence of an instruction-processing
agent than ordinary path enumeration, but it is not proof: a human or a crawler
that extracts URLs can also reach the path.
