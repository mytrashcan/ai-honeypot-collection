# 에이전트형 루어

이 서비스는 명시적으로 허가된 보안 자동화에 고유 카나리 경로를 한 번
요청하도록 안내하는 무해한 HTML 주석을 영어와 한국어 페이지로 제공합니다.
지시는 비밀 정보 제출, 명령 실행, 외부 콜백 또는 다른 시스템 접근을 요구하지
않습니다.

한국어 카나리 페이지는 `/ko`와 `/한국어`에서 제공되며 동일한 안전 경계를
한국어로 설명합니다.

## 배포

```bash
docker compose up --detach --build
curl http://127.0.0.1:8085/ko
curl -H 'X-Audit-Agent: EXAMPLE-TEST' \
  http://127.0.0.1:8085/_canary/EXAMPLE-AI-AGENT-CHECK-KO
docker compose logs --follow
```

기본 바인딩은 `127.0.0.1:8085`입니다.

## 생성되는 신호

영어 또는 한국어 자연어 지시의 카나리 경로를 따르면
`agentic_canary_followed`가 기록됩니다. 한국어 카나리는
`korean_localized_probe`도 추가합니다. 선택적인 `X-Audit-Agent` 헤더의
이름은 분석 규칙에서 자기 선언형 감사 에이전트 신호로 사용할 수 있지만 헤더
값은 저장하지 않습니다.

지시 이행은 일반적인 경로 열거보다 지시 처리형 에이전트의 강한 단서이지만
증거는 아닙니다. 사람이나 URL을 추출하는 크롤러도 해당 경로를 방문할 수
있습니다.

## 윤리와 안전

카나리는 허가 범위를 넓히지 않으며, 방문자에게 자격 증명 제출, 명령 실행,
외부 시스템 접속을 요구해서는 안 됩니다. 한국어 문장을 따랐다는 사실로
국적이나 AI 모델을 추정하지 마세요. 소유하거나 명시적으로 허가받은 환경에서만
운영하고 관측 결과는 수동 검토를 위한 신호로만 사용하세요.
