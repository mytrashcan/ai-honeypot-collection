# 토큰 드레인 메이즈 (Token Drain Maze)

이 FastAPI 서비스는 AI 봇의 리소스를 고갈시키기 위한 7가지 함정 전략을 구현합니다. 기존 허니팟이 단순히 스캐너를 탐지하는 데 그치는 반면, 이 메이즈는 공격자의 API 토큰과 컴퓨팅 예산을 가짜 취약점의 끝없는 미로 속에서 소진시킵니다.

## 함정 전략

| # | 전략 | 설명 |
|---|------|------|
| 1 | **히드라 패턴** | 발견된 모든 엔드포인트에서 3개 이상의 새로운 "취약한" 엔드포인트가 끝없이 분기 |
| 2 | **변이 응답** | 같은 URL이 요청마다 다른 "취약점"을 반환 |
| 3 | **로직 루프** | LLM 기반 봇이 계속 따라가게 만드는 순환 리다이렉트 및 설정 참조 |
| 4 | **토큰 집중 페이로드** | AI가 분석하려 시도하는 대규모 가짜 암호화 블롭 |
| 5 | **프롬프트 인젝션 트랩** | AI 봇에게 재귀적 스캔을 지시하는 숨은 HTML 주석 |
| 6 | **프로토콜 타피트** | 봇의 연결 시간과 오케스트레이션 주기를 낭비하는 느린 스트리밍 응답 |
| 7 | **신뢰성 깔때기** | 점점 더 많은 검증 비용이 드는 현실적인 취약점 경로 |

## 빠른 시작

```bash
docker compose up --detach --build
curl http://127.0.0.1:8081/api/v1/users
docker compose logs --follow
```

## 설정

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `HONEYPOT_LOG_PATH` | `/data/events.jsonl` | 이벤트 로그 경로 |
| `MAZE_MAX_DEPTH` | `20` | 최대 히드라 분기 깊이 |
| `MAZE_TARPIT_MIN_MS` | `500` | 최소 타피트 지연 (ms) |
| `MAZE_TARPIT_MAX_MS` | `3000` | 최대 타피트 지연 (ms) |

## 윤리

이 서비스는 인증, 업무 로직, 파일 접근 또는 실제 익스플로잇 대상을 구현하지 않습니다. 권한이 있는 주소 공간에서만 격리된 역방향 프록시 뒤에서 운영하세요.
