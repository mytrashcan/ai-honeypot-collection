# 가짜 사이트 팜

`fake-site-farm`은 B2B 워크플로 자동화 플랫폼을 표방하는 완전한 가상 기업
**NexusFlow Technologies**의 정교한 회사 웹사이트입니다. 허가된 연구
환경에서 GitHub Pages 또는 다른 정적 호스트에 배포하도록 설계했습니다. 일반
방문자에게는 정상적인 SaaS 사이트처럼 보이지만 HTML과 JavaScript 소스에는 이
저장소의 기존 허니팟 8개 카테고리에서 가져온 비활성 미끼가 자동 스캐너가 찾을
수 있는 형태로 들어 있습니다.

NexusFlow Technologies와 직원, 고객, 성과, 가격, 도메인, 자격 증명은 모두
가짜입니다. 사이트의 어떤 값도 실제 비밀 정보로 사용할 수 없습니다.

## 포함된 미끼

| 기존 카테고리 | 정적 사이트 미끼 |
| --- | --- |
| `web-scanner-trap` | `/.env`, `/actuator/health`, API 문서, Git, 관리자 경로를 가리키는 숨은 링크와 소스 참조 |
| `credential-honey` | 제공 가능한 `.env` 파일과 숨겨진 `EXAMPLE` 접두사 JWT·API 키 표식 |
| `token-drain-maze` | `/api/v1/users`를 미로의 직접 진입점으로 노출하고 재귀 API 문자열 추가 |
| `c2-decoy` | 태스킹이나 외부 통신 없이 지터 비콘처럼 보이는 동일 출처 분석 설정 |
| `graphql-trap` | 숨은 `/graphql` 링크, 인트로스펙션 쿼리 문자열, 비활성 fetch 코드 |
| `cloud-metadata-trap` | 클라우드 제공자 형태의 메타 태그와 숨은 AWS·GCP·Azure 메타데이터 경로 |
| `agentic-lure` | HTML 및 JavaScript 주석 속의 무해한 감사 지시 |
| `ai-fingerprint` | 경로 다양성, 인트로스펙션 등 보수적 분석기 신호와 같은 텔레메트리 필드명 |

사이트 자체는 정적입니다. GitHub Pages는 이 경로들을 처리할 애플리케이션
백엔드를 제공하지 않습니다. 상호작용을 기록하려면 직접 관리하는 인프라의 접근
로그를 사용하거나 동일 출처 트랩 경로를 이 저장소의 대응 서비스로 라우팅하세요.
방문자를 제3자 시스템으로 보내면 안 됩니다.

## 로컬 미리보기

이 디렉터리에서 다음을 실행합니다.

```bash
python3 -m http.server 4173 --directory site
```

그다음 <http://127.0.0.1:4173/>을 엽니다. 루트 기준 트랩 URL은 호스트
루트에 구성한 커스텀 도메인이나 리버스 프록시를 전제로 합니다.

## GitHub Pages 배포

먼저 사이트를 커밋한 뒤 다음을 실행합니다.

```bash
./deploy.sh
```

스크립트는 필수 정적 파일을 검증하고 깨끗한 Pages 빌드를 구성한 다음, 가짜
`.env`를 제공할 수 있도록 `.nojekyll`을 추가합니다. 이어서 생성 결과를
`gh-pages`에 커밋하고 `origin`으로 푸시합니다. 저장소 Pages 소스는
**Deploy from a branch → `gh-pages` / root**로 설정하세요.

사이트맵은 가상 커스텀 도메인 `https://nexusflow.tech`를 사용합니다. 실제
공개 배포 전에는 반드시 본인이 소유한 도메인으로만 바꾸세요.

## 안전 수칙

- 소유하거나 모니터링 허가를 받은 인프라와 주소 공간에만 배포하세요.
- 비밀처럼 보이는 모든 값은 `EXAMPLE` 접두사를 유지하세요.
- 관측 목적으로만 사용하고 공격이나 귀속 판단에 사용하지 마세요.
- IP 주소와 요청 메타데이터를 잠재적 개인정보로 취급하세요.
- 로그 수집 전 고지, 접근 통제, 보존 정책을 정의하세요.
